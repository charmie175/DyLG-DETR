# Data Availability statement

The source code and configuration files supporting this study are openly available in the Zenodo record **Qian, Lanmu (2026), _Deformable Local-Global DETR for Remote Sensing Object Detection_, Zenodo, https://doi.org/10.5281/zenodo.24150834**, licensed under the Creative Commons Attribution 4.0 International licence (CC BY 4.0). The version-controlled source repository is available at https://github.com/charmie175/DyLG-DETR. The remote-sensing benchmark datasets used in this study are third-party datasets and remain subject to their respective terms of use; this repository provides the scripts and configuration needed to reproduce the reported analyses.

Use the same author list, year, title, publisher, DOI, and licence in the manuscript reference list.
